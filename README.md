# File Renamer

A simple Python script that renames all files in a folder with numbered prefixes (001_, 002_, etc.).

## How to use

1. Change the `folder` path in `renamer.py` to your folder
2. Run: `python renamer.py`

## Example

Before: cat.jpg, dog.jpg, bird.jpg
After: 001_cat.jpg, 002_dog.jpg, 003_bird.jpg

Built by a Malaysian high school student learning Python automation.
